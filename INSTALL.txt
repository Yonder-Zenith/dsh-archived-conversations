DSH 归档对话插件 1.2.2
========================

安装步骤
--------

1. 解压这个压缩包，得到 archived-conversations 文件夹。

2. 打开 DSH，对 DSH 助手说：

   帮我安装本地 DSH 插件：<解压后的 archived-conversations 文件夹绝对路径>

   例如 Windows：
   帮我安装本地 DSH 插件：D:\Tools\archived-conversations

3. 安装完成后，完全退出 DSH，再重新打开。
   Host 半的路由需要重启 DSH 才会加载，只刷新页面不够。

4. 重新进入 DSH 后，点击左侧栏的「归档对话」图标。

功能
----

- 集中查看所有已归档对话
- 显示每个会话的日志大小和归档总大小
- 恢复、打开
- 删除：Windows 送入系统回收站（可在资源管理器回收站恢复或清空）；
  macOS/Linux 移到 <用户目录>/.dsh/session-trash。
  清空回收站前不会释放磁盘空间。

要求与注意
----------

- 需要 DSH Web UI。
- 插件针对当前 DSH 版本开发；如果 DSH 版本差异较大，
  工作区隐藏、日志大小或删除功能可能失效。
- 删除只允许作用于已归档且不活跃的会话；
  有 subagent 子会话的会话需要先处理子会话。
